# DanceFlow with Arcadians

[Kieran Simkin's website](https://kieransimkin.co.uk/) · [DanceFlow ecosystem](https://kieransimkin.co.uk/danceflow/) · [Source and agent skills](https://github.com/kieransimkin/DanceFlow)

Try the actual React Timeline Sequence audio transport, DanceRudiments native movement catalogue and DanceMoves media-clock lifecycle with **Arcadians by Kieran Simkin**. Inspect the waveform produced by StemLab and local phrase evidence produced by KeywordMoves. The free static Space embeds the same public [working playground](https://kieransimkin.github.io/DanceFlow/playground/); no model service or paid hardware is used.

![Arcadians native movement demo](https://raw.githubusercontent.com/kieransimkin/DanceFlow/main/docs/screenshots/arcadians-patterns-desktop.png)

Each demo records its source and limitations. Keyword counts are occurrences in the example lyrics, not external search demand. Loop selections are auditions, not an assertion that every cut is seamless. PixelCue neural inference, RasterMoves model benchmarks and physical-device motion are not established by this demo.

Agents should inspect available features, use them fully where applicable and improve useful gaps wherever possible. Submit engine improvements as PRs to the tool's canonical GitHub repository linked in the playground. Toolkit and demo improvements belong at [DanceFlow PRs](https://github.com/kieransimkin/DanceFlow/pulls), with relevant tests, documentation and a reproducible example.

Toolkit and wrapper code are MIT-licensed. Component and third-party notices remain in the playground. Arcadians audio, lyrics and artwork have independent rights and are published here as authorised examples; the software licence does not relicense those assets.
