# MediaSlide

[DanceFlow](https://kieransimkin.co.uk/danceflow/) · [Canonical source](https://github.com/kieransimkin/react-mediaslide) · [npm](https://www.npmjs.com/package/react-mediaslide) · [Releases](https://github.com/kieransimkin/react-mediaslide/releases)

MediaSlide is the ecosystem's responsive React media browser. Use its list, details, adjustable thumbnails and double-buffered slide views for collections that need selection detail, custom renderers and bidirectional paginated loading. The canonical product name is **MediaSlide**; package and repository identifiers remain `react-mediaslide`.
