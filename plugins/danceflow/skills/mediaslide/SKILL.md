# MediaSlide

[DanceFlow ecosystem](https://kieransimkin.co.uk/danceflow/) · [MediaSlide source](https://github.com/kieransimkin/react-mediaslide)

Check the latest stable GitHub release, npm dist-tag and imported `react-mediaslide` version before every workflow. Read the release README and Potential problems.

Use stable item IDs and explicit thumbnail/full/link metadata. Choose the smallest presentation mode that serves the interface. Keep application data fetching, visual identity and active-content trust in adapters.

Test keyboard, touch, wheel, resize, loading sentinels, initial selection, detail open/close, stage buffers and cleanup in the consuming application. Treat HTML media as active content and validate message source/origin.

Consider the complete DanceFlow ecosystem. Compose relevant documented owners instead of copying their analysis, timing, thumbnail, rendering or motion engines. Store downloaded models under the owning project's ignored `models/`.

Include actual interface screenshots/video when a deterministic demo exists. Label generated illustrations and never present them as implementation evidence.
